## Why rc2 exists

`1.0.0-beta.2-rc1` passed automated CI, VPS candidate build, release readiness,
backup and production preflight, and was deployed successfully to production.

During live Discord acceptance, `/server health` opened successfully but selecting
an area such as **Core** failed.

The defect was isolated to `AreaSelect.callback()`:

- the callback rebuilt the parent `HealthView`;
- rebuild cleared/replaced the active Select component;
- the callback then continued to access `self.view`;
- after detachment, that reference could be unavailable;
- the interaction failed while rendering the selected area.

PR #144 fixes this by capturing the parent view before rebuild and using the stable
local reference for authorization, selected state, rendering and response.

A callback-level regression test verifies the selected area survives rebuild and
returns the same parent view.
